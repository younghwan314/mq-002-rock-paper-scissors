# 가위바위보 게임 구현 계획

## 목표

콘솔에서 사용자가 한글로 "가위/바위/보"를 입력해 컴퓨터와 대결하는 게임.
여러 판을 이어서 할 수 있고, 종료할 때 전적을 보여준다.

범위: 1~3단계 (4단계 확장 기능은 이번 범위에서 제외)

## 클래스 구성 (패키지 `com.slotmaster`)

| 클래스 | 역할 |
|---|---|
| `Hand` (enum) | 가위, 바위, 보와 각 손의 한글 이름 |
| `Result` (enum) | 승, 패, 무승부 |
| `Referee` | 두 손을 받아 `Result` 판정 |
| `ComputerPlayer` | 무작위로 `Hand` 선택 (`Random`을 생성자로 주입) |
| `InputParser` | 한글 문자열을 `Hand`로 변환 |
| `Scoreboard` | 승/패/무 횟수 집계 |
| `Game` | 입력 → 선택 → 판정 → 출력 → 반복 흐름 제어 |
| `Main` | `Game`을 생성하고 실행 (현재 IntelliJ 기본 코드를 대체) |

설계 원칙: 규칙(판정, 파싱, 집계)은 콘솔 입출력과 분리해서 입출력 없이 단위 테스트할 수 있게 한다.

## 기능 목록

### 1단계: 핵심 규칙

**기능 1. 손 모양 (`Hand`)**
- `ROCK`, `PAPER`, `SCISSORS`에 한글 이름("바위", "보", "가위")을 붙인다.
- 테스트: 각 손의 한글 이름 확인

**기능 2. 승패 판정 (`Result`, `Referee`)**
- 사용자 손과 컴퓨터 손을 받아 사용자 기준의 승/패/무승부를 돌려준다.
- 테스트: 가능한 9가지 조합을 모두 확인

**기능 3. 컴퓨터 선택 (`ComputerPlayer`)**
- `Random`으로 세 손 중 하나를 고른다.
- 테스트
  - `nextInt`가 정해진 수를 돌려주는 가짜 `Random`(익명 클래스)을 넣어, 0/1/2가 각각 바위/보/가위로 바뀌는지 확인
  - 시드를 고정한 `Random`으로 100번 골라 세 가지 손이 모두 나오는지 확인

### 2단계: 한 판 플레이

**기능 4. 사용자 입력 처리 (`InputParser`)**
- "가위", "바위", "보"를 `Hand`로 바꾼다. 앞뒤 공백은 무시한다.
- 그 외 입력은 잘못된 입력으로 처리한다.
- 테스트: 올바른 입력 3가지, 공백이 포함된 입력, 잘못된 입력("가우", "", "rock" 등)

**기능 5. 한 판 진행 (`Game`)**
- 입력 받기 → 컴퓨터 선택 → 판정 → 결과 출력
- 잘못 입력하면 안내 메시지를 보여주고 다시 입력받는다.
- 출력 예시:
  ```
  가위, 바위, 보 중 하나를 입력하세요: 바위
  컴퓨터: 가위
  이겼습니다!
  ```
- 테스트: 입력 스트림과 출력 스트림을 주입해서 출력 내용 확인
- 부수 작업: `build.gradle`에 `application` 플러그인과 `run { standardInput = System.in }`을 추가해 `./gradlew run`으로 실행할 수 있게 한다.

### 3단계: 게임다운 흐름

**기능 6. 반복 플레이**
- 한 판이 끝나면 "한 판 더 할까요? (y/n)"를 묻는다.
- `y`면 계속하고 `n`이면 종료한다. 그 외 입력은 다시 묻는다.
- 테스트: 여러 판 입력 후 종료되는지 확인

**기능 7. 점수 집계 (`Scoreboard`)**
- 판마다 결과를 기록하고, 종료할 때 전적을 출력한다.
- 출력 예시: `전적: 3승 1패 2무`
- 테스트: 결과 기록 후 횟수 확인, 종료 시 출력 확인

## 진행 방식

- 기능 1부터 하나씩 구현한다. 각 기능마다 테스트를 작성하고 실행한다.
- 기능 하나가 끝나면 설명한 뒤 커밋 여부를 확인받는다.
